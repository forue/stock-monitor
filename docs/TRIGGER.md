# 异动触发说明

> 版本：v4.1 | 更新：2026-05-12

## 监控流程

```
L1 初筛 → L2 确认 → 阶梯式递增判断 → 场景分类 → QQ 推送
  │            │              │               │
  ≥2条件      三路径         趋势/反转/       9种场景
  +连续命中   任一满足        时间衰减/极端     标签
```

---

## 第一级：L1 初筛

**至少 2 个条件同时满足** + **连续 2 次命中**（防止瞬时脉冲误报）。

| 指标 | 阈值 | 说明 |
|------|------|------|
| 价格波动率 (price_change_rate) | ≥ 1.0% | 现价偏离昨收的绝对比例 |
| 涨跌幅 (price_change_pct) | ≥ ±2.5% | 涨跌幅绝对值 |
| 量比 (volume_ratio) | 分时段动态 | 见下方分时段配置 |
| 盘中振幅 (amplitude) | ≥ 2.0% | (最高价-最低价)/昨收 |

> 单一条件满足不触发，必须 ≥ 2 条件同时命中 + 连续 2 次。

---

## 第二级：L2 确认

三种确认路径，**任一满足**即确认异动，同样需连续 2 次命中：

| 路径 | 条件 | 设计意图 |
|------|------|----------|
| **A. 量价共振** | 涨跌幅 ≥ 3.0% **且** 量比 ≥ 分时段阈值 | 价格运动有成交量背书，主力资金介入 |
| **B. 极端涨跌** | \|涨跌幅\| ≥ 5.0% | 剧烈价格变动优先告警，忽略量比 |
| **C. 极端放量** | 量比 ≥ 6.0x **且** \|涨跌幅\| ≥ 1.0% | 成交异常放大，即使价格变化不大也可能预示变盘 |

### 分时段动态量比阈值

| 时段 | 时间 | L1 量比 | L2 量比 | 说明 |
|------|------|---------|---------|------|
| 开盘 | 09:30-10:00 | 3.0 | 5.0 | 集合竞价导致量比虚高 |
| 早盘 | 10:00-11:30 | 2.0 | 3.0 | 正常交易 |
| 午后 | 13:00-14:30 | 2.0 | 3.0 | 正常交易 |
| 收盘 | 14:30-15:00 | 2.5 | 4.0 | 尾盘放量常见 |

---

## 第三级：阶梯式递增告警

替换固定时间间隔，按价格偏离实质性演化时才再推送。

### 规则优先级

```
1. 极端行情 (≥ ±6.0%)
   → 强制推送，不检查冷却和阶梯
   → 不计入非极端每日上限

2. 冷却保护 (< 动态冷却秒数)
   → 跳过（极端行情除外）
   → 冷却时长 = 基础180s × 波动率系数 (0.5x ~ 3.0x)

3. 趋势延续 (同向 + 偏离 ≥ 2.0%)
   → 推送 [涨势加速/跌势加速]

4. 方向反转 (反向 + 偏离 ≥ 1.5%)
   → 推送 [低位反弹/高位回落]

5. 时间衰减 (≥ 30min + 偏离 ≥ 1.0%)
   → 推送 [时间衰减]
```

### 上限兜底

| 类型 | 每日上限 | 说明 |
|------|----------|------|
| 非极端告警 | 8 次/天/股 | 正常阶梯推送 |
| 绝对总量 | 15 次/天/股 | 含极端行情 |

## 9 种异动场景

| 场景 | 图标 | 触发条件 | 含义 |
|------|------|----------|------|
| 量价共振 | 📊 | L2-A 路径 | 价量同向，主力资金介入 |
| 急速拉升 | 🚀 | L2-B 路径 (上涨) | 涨幅 ≥ 5%，关注持续性 |
| 急速下跌 | 💥 | L2-B 路径 (下跌) | 跌幅 ≥ 5%，利空或错杀 |
| 异动放量上攻 | 📈 | L2-C 路径 (上涨) | 巨量上涨，吸筹或出货 |
| 异动放量下砸 | 📉 | L2-C 路径 (下跌) | 巨量下跌，恐慌或洗盘 |
| 涨势加速 | 🔥 | 阶梯-趋势延续 (上涨) | 同向扩大，趋势强化 |
| 跌势加速 | 🧊 | 阶梯-趋势延续 (下跌) | 同向扩大，趋势恶化 |
| 低位反弹 | 🔄 | 阶梯-方向反转 (上涨) | 跌后反转，可能见底 |
| 高位回落 | ⚠️ | 阶梯-方向反转 (下跌) | 涨后反转，可能见顶 |

## 技术指标买卖信号

独立于异动监控，低频运行（默认 300s/次），不阻塞异常检测。

### 触发规则

| 信号 | 条件 | 过滤条件 |
|------|------|----------|
| 金叉 (买入) | MA`fast` 上穿 MA`slow` | 收盘价 ≥ MA`filter` × `filter_pct` (默认 80%) **且** RSI < `rsi_max` (默认 70) |
| 死叉 (卖出) | MA`fast` 下穿 MA`slow` | 无附加条件 |

### 防重复

- 同方向信号：`min_signal_interval` 秒内不重复（默认 3600s）
- 不同方向信号（金叉→死叉）：不受间隔限制
- 每日上限：3 次/股

### 消息格式

**买入信号：**
```
🔔 【买入信号】价量齐动 + 技术面共振

📊 上汽集团 (600104)
💰 当前价：¥15.50
📈 MA8=15.20 上穿 MA20=14.80 ✅
📊 MA60=15.00，收盘价占比 103.3%（≥80%✅）
📉 RSI14=62.5（<70✅）
⏰ 时间：09:58:15
```

**卖出信号：**
```
🔻 【卖出信号】技术面死叉

📊 上汽集团 (600104)
💰 当前价：¥14.80
📉 MA8=14.50 下穿 MA20=14.90 ⚠️
⏰ 时间：14:25:30
```

## 动态检查间隔

波动率越高，检查越密：

| 波动率 | 间隔 | 适用时段 |
|--------|------|----------|
| ≥ 2.0% | 3 秒 | 开盘/收盘高波动时段降至 2s |
| 1.0% ~ 2.0% | 3 秒 | 所有交易时段 |
| < 1.0% | 8 秒 | 正常交易时段 |
| 休市/非交易 | 300 秒 | 午休/盘后/周末/节假日 |

## 告警消息格式

### 首次告警（量价共振）

```
📊 【量价共振】价量同向异动，主力资金介入信号

📊 上汽集团 (600104)
💰 当前价：¥14.32
📊 涨跌幅：+3.25%
📈 量比：3.50
📊 振幅：4.12%
⏰ 时间：09:35:30

🚨 触发条件:
  • 连续命中: 2/2
  • 涨跌幅=+3.25%(阈值±2.5%)
  • 量比=3.50(阈值3.0[opening])

✅ 确认异动:
  • 量价共振: 涨跌幅=+3.25%(阈值±3.0%) + 量比=3.50(阈值5.0) ✅
```

### 趋势延续告警（含参考锚点）

```
🔥 【涨势加速】同向持续扩大，趋势强化

📊 上汽集团 (600104)

📈 量比：4.10
📍 上次告警: ¥14.32 (上涨) → 当前偏离 +4.40%
⏰ 时间：09:58:15
...
```
