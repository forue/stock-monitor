# 异动触发说明

> 版本：v1.0 | 更新：2026-04-07

## 监控概览

```
L1 轮询扫描 → 触发任一阈值 → L2 二次验证 → 确认异动 → QQ 推送
  (免费)         ↓             (免费/付费)
              东方财富        降级为免费
              实时数据        数据
```

## 两级触发机制

### 第一级：L1 扫描预警（免费数据，东方财富）

**任一**指标达到阈值即触发进入 L2 验证：

| 指标 | 阈值 | 说明 |
|------|------|------|
| 价格波动率 (price_change_rate) | ≥ 0.7% | 现价偏离昨收的绝对比例 |
| 涨跌幅 (price_change_pct) | ≥ 2.5% | 涨跌幅绝对值 |
| 量比 (volume_ratio) | ≥ 2.5x | 成交量 / 近5日均量 |
| 盘中振幅 (amplitude) | ≥ 2% | (最高价-最低价)/昨收 |

> ⚠️ 以上 4 个指标只要 **任意一个** 达标就触发 L2

### 第二级：L2 确认告警

L2 验证 **任一**条件满足即确认异动，推送 QQ 告警：

| 指标 | 阈值 | 说明 |
|------|------|------|
| 涨跌幅 (price_change_pct) | ≥ 3.0% | 涨跌幅绝对值 |
| 量比 (volume_ratio) | ≥ 3.0x | 成交量 / 近5日均量 |

> L2 是确认层，避免 L1 误触。只有 L2 通过后才会真正推送。

## 推送规则

- **防重复**：同一只股票两次告警间隔 ≥ 300 秒（5 分钟）
- **通道**：QQ C2C 私聊直推（通过 QQ 开放平台 API）
- **兜底**：推送失败时仍会写入 `logs/alerts.json` 和 `logs/qq-alert-queue.jsonl`
- **失败不静默**：告警写入文件备份，即使 QQ 推送失败也能回溯

## 告警消息格式

```
📈 股票异动告警           ← 📈 涨  📉 跌
📊 上汽集团 (600104)     ← 名称 + 代码
💰 当前价：¥14.32         ← 实时价格
📊 涨跌幅：+3.25%        ← 涨跌幅带正负号
📈 量比：3.15            ← 量比倍数
⏰ 时间：14:25:30         ← 触发时间

请速速查看！🦐
```

## 动态检查间隔

交易时段内根据波动率动态调整轮询频率：

| 情况 | 间隔 | 说明 |
|------|------|------|
| 高波动期开盘/收盘 | 2 秒 | 9:30-10:00, 14:30-15:00 |
| 正常交易时段 | 5 秒 | 10:00-11:30, 13:00-14:30 |
| 波动率 ≥ 2% | 1 秒 | 极端波动，极速响应 |
| 波动率 ≥ 1% | 2 秒 | 较高波动 |
| 波动率 ≥ 0.5% | 间隔减半 | 适度加快 |
| 休市/非交易 | 300 秒 | 节能模式 |

## 交易时段

| 时段 | 时间 | 状态 |
|------|------|------|
| 盘前 | 09:30 前 | 休眠 |
| 早盘 | 09:30 - 11:30 | ✅ 监控 |
| 午间 | 11:30 - 13:00 | 休眠 |
| 午后 | 13:00 - 15:00 | ✅ 监控 |
| 盘后 | 15:00 - 次日 09:30 | 休眠 |

周末和 A 股节假日不交易，全程休眠。

## 调整阈值

编辑 `config.json`：

```json
{
  "l1_thresholds": {
    "price_change_pct": 2.5   // 调低=更敏感，调高=更少误报
  },
  "l2_thresholds": {
    "price_change_pct": 3.0
  },
  "notification": {
    "min_alert_interval": 300  // 告警间隔（秒）
  }
}
```
